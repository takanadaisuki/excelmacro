VBAとは？

VBA（Visual Basic for Applications）は、ExcelなどのOfficeアプリを自動操作するために使えるプログラミング言語です。

言葉ざっくり意味
マクロ自動化された処理・仕組み
VBAその処理を記述・編集するための言語

3. セルのコピーにもいろいろある

全部コピー・値だけ・書式だけ・数式を含むコピーなど、目的に応じて使い分けます。

実際のVBAコード

全部コピー

Range("A1").Copy Destination:=Range("B1")

Application.CutCopyMode = False

値だけコピー（PasteSpecial）

Range("A1").Copy
Range("B1").PasteSpecial Paste:=xlPasteValues

Application.CutCopyMode = False

値だけなら直接代入もできる

Range("B1").Value = Range("A1").Value

書式だけコピー

Range("A1").Copy
Range("B1").PasteSpecial Paste:=xlPasteFormats

Application.CutCopyMode = False
ポイント： Application.CutCopyMode = False を最後に入れると、Excelのコピー／切り取りモードを解除できます。

4. セルの指定方法：Range と Cells

RangeはA1形式、Cellsは行番号・列番号で指定できます。

' A1セル
Range("A1")

' A1からC3まで
Range("A1:C3")

' 3行目・3列目 = C3
Cells(3, 3)

' Cellsを組み合わせてA1:C3
Range(Cells(1, 1), Cells(3, 3))
使い分け： 人が見て分かりやすい指定は Range("A1")。 ループなどで行・列の番号を変えながら処理したいときは Cells(row, col) が便利です。

5. VBAはExcelの外も扱える

フォルダ内のファイル名を取得し、Excelへ一覧として書き出す例です。

フォルダ内のファイルを順番に取得

Dim fileName As String

fileName = Dir("C:\Sample\*.*")

Do While fileName <> ""

    Debug.Print fileName

    fileName = Dir()

Loop

取得したファイル名をExcelへ書き出す

Dim fileName As String
Dim row As Long

row = 1
fileName = Dir("C:\Sample\*.*")

Do While fileName <> ""

    Cells(row, 1).Value = fileName

    row = row + 1
    fileName = Dir()

Loop
フォルダ一覧だけでなく、対象ファイルを順番に開いて集計したり、CSVを読み込んだりする処理にも発展できます。

6. 注意：マクロは「元に戻す」が基本的に使えない

⚠ Ctrl + Z が使える前提で実行しない

通常のExcel操作は「元に戻す」で戻せますが、VBAマクロを実行すると通常のUndo履歴がクリアされるため、マクロによる変更をCtrl + Zで元に戻すことは基本的にできません。

セル変更 → マクロ実行 ⚡ → Ctrl + Z ✕

重要なファイルでは、バックアップやコピーを作ってから試すのが安全です。
